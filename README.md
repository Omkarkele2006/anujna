# ANUJNA

**ANUJNA** (A Consent-Driven Unified Health Identity Platform) is a healthcare governance platform designed around **patient-controlled healthcare data sharing**, **consent-driven access management**, **auditability**, and **emergency access governance**.

The platform aims to place patients at the center of healthcare information exchange while providing healthcare providers with secure, transparent, and accountable access workflows.

---

## Vision

Enable patients to remain the primary authority over access to their healthcare records through secure, transparent, and consent-driven healthcare information sharing.

---

## Core Features

* Unique Health Identity Management
* Health Record Repository
* Consent-Based Record Sharing
* Doctor Verification Workflow
* Access Request Management
* Emergency Access Governance
* Role-Based Access Control (RBAC)
* Audit Logging and Transparency
* Notification System
